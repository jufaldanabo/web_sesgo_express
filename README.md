# Sesgo Express — Sitio Web Oficial

Página web corporativa de **Sesgo Express**, fábrica de sesgo textil con más de 20 años de experiencia en Medellín, Colombia.

---

## 🌐 Despliegue

Este sitio está desplegado en **[Netlify](https://netlify.com)** con dominio propio registrado en **[Namecheap](https://namecheap.com)**.

- **URL en producción:** `https://www.sesgoexpress.com` *(actualizar cuando esté activo)*
- **Rama de producción:** `main`
- **Deploy automático:** Cada vez que se sube un cambio a este repositorio, Netlify actualiza el sitio automáticamente en ~30 segundos.

## ✏️ Cómo hacer cambios

1. Edita el archivo `index.html` (todo el código está en ese único archivo)
2. Si cambias imágenes, reemplaza el archivo manteniendo el mismo nombre
3. Sube los cambios a GitHub (arrastra el archivo al repositorio)
4. Netlify detecta el cambio y actualiza el sitio automáticamente
